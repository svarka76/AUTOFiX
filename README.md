# AUTOFiX

Сайт автомобильного сервиса. Чистые HTML, CSS и JavaScript — без сборщиков и платных библиотек.

## Структура

```
AUTOFiX/
├── index.html      — разметка страницы
├── style.css       — стили (цвета и размеры — в блоке :root вверху)
├── script.js       — меню, поведение шапки
├── README.md
└── assets/images/  — изображения сайта
```

## Изображения

Положите файлы в `assets/images/` с точно такими именами:

| Файл | Где используется |
|---|---|
| `hero.jpg` | главный экран (горизонтальное, от 1920×1080) |
| `service-repair.jpg` | услуга «Ремонт» |
| `service-diagnostics.jpg` | услуга «Диагностика» |
| `service-maintenance.jpg` | услуга «Обслуживание» |
| `gallery-1.jpg` … `gallery-4.jpg` | галерея |

Пока файлов нет, на их месте показывается цветная заглушка. Используйте качественные фото с бесплатных сток-сервисов с разрешённой коммерческой лицензией или собственные снимки. Сжимайте их (до ~300 КБ), чтобы сайт грузился быстро.

## Запуск

Откройте `index.html` в браузере.

## Публикация (Cloudflare Pages)

1. Загрузите проект в репозиторий GitHub `AUTOFiX`.
2. В Cloudflare Pages: Create project → Connect to Git → выберите репозиторий.
3. Build command — пусто, Output directory — `/` (корень).

## Что заменить

Телефон, адрес и почту в блоке «Контакты» в `index.html` — сейчас там заглушки.
